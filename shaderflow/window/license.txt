Files here derive from moderngl-window [1] with significant changes:

- Kept only GLFW and Headless window backends
- Converted to attrs with typed fields, global keys enum
- Removed pyglm (slow to update new cpython), pyglet dependencies
- Reduced to bare minimum window implementations compatible with scene.py
- Integrated pull request #224 for imgui-bundle v1.92+ integration [2]
- Faster import times than loading moderngl-window scene resources

Disclaimer: Code porting and refactoring was assisted by LLMs, with strong
  steering and guidelines, mostly verbatim copies and removals around

[1] https://github.com/moderngl/moderngl-window
[2] https://github.com/moderngl/moderngl-window/pull/224
